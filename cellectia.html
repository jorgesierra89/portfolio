Arquitectura avanzada para consultas inteligentes sobre documentación técnica masiva.

⚠️ Nota sobre la Demo: Esta versión pública utiliza un modelo optimizado (más ligero) para balancear coste y rendimiento. La arquitectura permite desplegar modelos de mayor escala según las necesidades de computación.

El Reto

En entornos educativos, localizar información específica en manuales extensos es ineficiente. El objetivo era crear un sistema capaz de responder basándose con precisión únicamente en la documentación técnica proporcionada, evitando alucinaciones de la IA.

Solución Técnica

RAG: Recuperación de información vectorizada para contexto real y preciso. Cloud: Sistema dockerizado desplegado en Hugging Face con capacidad de escalado GPU. DevOps: Arquitectura API (FastAPI) integrada en Vercel para optimización de costes.

Optimización de Recursos (Panel de Control)

He desarrollado un Panel de Control dedicado que permite gestionar el ciclo de vida de la instancia en Hugging Face. Mediante esta herramienta, se puede arrancar o pausar la instancia GPU según la demanda, optimizando el consumo y evitando costes innecesarios de computación en la nube.

Stack Tecnológico Utilizado

Python Hugging Face FastAPI Docker Vercel RAG / Vector DB
