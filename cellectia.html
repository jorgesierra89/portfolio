Cellectia - Ecosistema de IA Educativa

Demo Funcional

Arquitectura avanzada para consultas inteligentes sobre documentación técnica masiva, utilizando recuperación de información vectorizada.

El Reto

En entornos educativos y técnicos, localizar información específica dentro de manuales extensos es ineficiente. Los LLMs tradicionales tienden a alucinar si no se les proporciona el contexto exacto. El objetivo era crear un ecosistema capaz de leer, comprender y responder basándose únicamente en la documentación proporcionada.

Solución Técnica

RAG: Generación aumentada por recuperación para contexto real. Cloud: Dockerizado en Hugging Face con escalado GPU. DevOps: API Node.js/FastAPI en Vercel para control de costes.
