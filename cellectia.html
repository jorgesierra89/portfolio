Cellectia - Ecosistema de IA Educativa

Demo Funcional

Arquitectura avanzada para consultas inteligentes sobre documentación técnica masiva, utilizando recuperación de información vectorizada.

⚠️ Nota sobre la Demo: Esta versión pública utiliza un modelo optimizado para balancear coste y rendimiento. A diferencia de la versión completa, esta demo está diseñada para mostrar la capacidad de la arquitectura RAG sin incurrir en costes de computación GPU masiva constante.

El Reto

En entornos educativos y técnicos, localizar información específica dentro de manuales extensos es ineficiente. El objetivo era crear un ecosistema capaz de responder basándose únicamente en la documentación proporcionada.

Solución Técnica

RAG: Generación aumentada por recuperación para contexto real. Cloud: Dockerizado en Hugging Face con escalado GPU. DevOps: API (FastAPI) en Vercel para control de costes.

Optimización de Recursos (Panel de Control)

Para garantizar la sostenibilidad del proyecto, he desarrollado un Panel de Control dedicado. Este permite gestionar el estado de la máquina en Hugging Face (HF), permitiendo arrancar o pausar la instancia GPU según la demanda. Esto optimiza el consumo de recursos y evita costes innecesarios cuando el sistema no está en uso activo.
