Automatización Inteligente On-Premise para Odoo ERP

El Reto

Muchas empresas evitan el uso de IAs generativas por el riesgo que supone enviar datos sensibles de clientes y facturación a servidores externos. El reto era crear una solución que permitiera disfrutar de la potencia de los LLMs sin que ningún dato saliera de la infraestructura local de la empresa.

La Solución

Desarrollamos un plugin nativo para Odoo que actúa como puente con un servidor de inferencia privado. El sistema procesa peticiones en lenguaje natural para automatizar flujos de trabajo, como la creación de presupuestos, garantizando el cumplimiento estricto del RGPD.

Arquitectura y Funcionamiento

El proyecto se diseñó para ser modular y seguro, centrando toda la interacción dentro del ecosistema Odoo:

  • Interfaz Odoo: El usuario interactúa directamente desde un módulo personalizado en el panel de Odoo, enviando instrucciones simples por texto.
  • Procesamiento Local: La petición se envía a un servidor local donde un modelo de lenguaje extrae las entidades (productos, cantidades, clientes) y genera una respuesta estructurada en formato JSON.
  • Acción sobre el ERP: El sistema interpreta los datos recibidos, valida el stock y los precios en la base de datos de Odoo y genera automáticamente el documento correspondiente.

Puntos Fuertes del Proyecto

Privacidad Absoluta

Al utilizar modelos On-Premise, la información confidencial nunca abandona el servidor de la empresa, eliminando riesgos de seguridad y filtraciones.

Optimización de Procesos

Reduce el tiempo de creación de documentos administrativos, permitiendo que perfiles no técnicos gestionen tareas complejas mediante lenguaje natural.
